# 🌐 CryptoLwei — v1 Educational Site

> **The origin story.** This is where it all began.

CryptoLwei v1 was the first public-facing project under the CryptoLwei brand — 
a fully hand-built educational website designed to demystify cryptocurrency, 
blockchain, and Web3 for everyday people.

Built in **2024** by **Augusto Faustino** and **Suphee Yangnok**, this site laid 
the foundation for what CryptoLwei is today.

## 🛠️ Tech Stack
- HTML5 (multi-page, 20+ pages)
- Tailwind CSS (CDN) + custom `cryptolwei.css`
- Vanilla JS for mobile nav & scroll
- Google Fonts — Inter
- Hosted at cryptolwei.com

## 🧭 The Evolution
This was **version 1**. The journey continued:
- 📦 cryptolwei-site-v2 — Evolved portfolio site
- ⛓️ CryptoLwei-DeFi-PoC — Gamified NFT learning on Algorand
- 🔷 evolving-kitties-eth — Breedable NFTs on Ethereum (Solidity)
- 🪙 cryptolwei-token — ERC-20 token on Ethereum (Solidity)
